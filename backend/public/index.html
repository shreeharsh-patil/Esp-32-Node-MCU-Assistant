Connect your ESP32

  1. Join Shreeharsh Assistant Wi-Fi using the setup key on its display.
  2. Open http://192.168.4.1 and enter your home Wi-Fi, backend URL and device token.
  3. Use the DEVICE_TOKEN from Vercel for the first connection, or create a device below for a separate token. An authenticated first connection appears here automatically.
